# Olyvera

## 1. Présentation

**Nom :** Olyvera

**Type :** Plateforme personnelle de santé

**Objectif :** Permettre à chaque utilisateur de disposer d'un espace personnel de santé, de prendre des rendez-vous physiques avec des professionnels de santé et de consulter les informations médicales enregistrées et validées par les professionnels autorisés.

Olyvera met l'accent sur la confidentialité, la traçabilité et le contrôle des accès aux données médicales.

---

## 2. Utilisateurs

La plateforme comprend quatre principaux types d'utilisateurs :

* Patient
* Médecin
* Établissement de santé
* Administrateur

---

## 3. Principe central

Les données médicales d'un patient sont privées.

Le patient contrôle les autorisations permettant aux professionnels ou aux personnes de confiance d'accéder à certaines informations.

Les données médicales professionnelles sont créées ou validées par des professionnels de santé autorisés.

Un lien familial ou un rendez-vous ne donne pas automatiquement accès au dossier médical.

---

# 4. Patient

## 4.1 Informations personnelles

Le patient peut :

* créer son compte ;
* gérer son nom et ses informations personnelles ;
* gérer sa photo de profil ;
* modifier ses coordonnées ;
* gérer ses informations de contact ;
* gérer ses paramètres de compte.

## 4.2 Fonctionnalités

Le patient peut :

* rechercher un médecin ;
* rechercher un établissement de santé ;
* consulter les spécialités des médecins ;
* consulter les disponibilités ;
* prendre un rendez-vous physique ;
* consulter ses rendez-vous ;
* annuler un rendez-vous ;
* consulter son historique médical validé par les professionnels ;
* consulter ses prescriptions ;
* consulter ses résultats d'examens ;
* consulter ses documents médicaux ;
* gérer ses relations familiales ;
* gérer ses personnes de confiance ;
* gérer les autorisations d'accès à ses données ;
* consulter l'historique des accès à son dossier.

## 4.3 Données médicales

Le patient **ne peut pas créer ou modifier librement les données médicales professionnelles** telles que :

* groupe sanguin ;
* allergies médicales ;
* antécédents médicaux ;
* diagnostics ;
* maladies diagnostiquées ;
* consultations ;
* prescriptions ;
* examens médicaux ;
* résultats médicaux ;
* observations médicales.

Ces informations sont renseignées ou validées par les professionnels de santé autorisés.

---

# 5. Médecin

## 5.1 Profil professionnel

Le médecin peut :

* créer son profil professionnel ;
* renseigner sa spécialité ;
* renseigner ses qualifications ;
* renseigner son lieu d'exercice ;
* être rattaché à un établissement de santé ;
* définir ses disponibilités.

## 5.2 Gestion des patients

Le médecin peut :

* consulter les dossiers des patients auxquels il est autorisé à accéder ;
* consulter l'historique médical autorisé ;
* consulter les informations nécessaires à la prise en charge ;
* créer une consultation ;
* clôturer une consultation.

## 5.3 Informations médicales

Le médecin peut renseigner :

* groupe sanguin ;
* allergies ;
* antécédents ;
* diagnostics ;
* maladies diagnostiquées ;
* observations médicales ;
* consultations ;
* prescriptions ;
* examens demandés ;
* résultats et interprétations ;
* traitements.

Chaque information médicale importante doit pouvoir être associée à un professionnel, une date et, lorsque nécessaire, à une consultation.

## 5.4 Rendez-vous

Le médecin peut :

* recevoir des demandes de rendez-vous ;
* accepter une demande ;
* refuser une demande ;
* consulter son agenda ;
* gérer ses disponibilités ;
* marquer un rendez-vous comme terminé ;
* marquer un patient comme absent.

---

# 6. Établissement de santé

L'établissement représente une structure médicale présente sur la plateforme.

## 6.1 Gestion de l'établissement

Il peut gérer :

* son profil ;
* ses coordonnées ;
* ses services ;
* ses spécialités ;
* ses horaires ;
* ses médecins rattachés.

## 6.2 Gestion des médecins

L'établissement peut :

* ajouter ou inviter des médecins ;
* gérer les médecins rattachés à l'établissement ;
* consulter leurs informations professionnelles ;
* organiser leurs services et disponibilités.

## 6.3 Rendez-vous

L'établissement peut :

* consulter les rendez-vous liés à ses services ;
* organiser les disponibilités ;
* gérer les rendez-vous selon ses droits ;
* consulter les patients pris en charge dans le cadre autorisé.

---

# 7. Administrateur

L'administrateur assure la gestion générale de la plateforme.

Il peut :

* gérer les utilisateurs ;
* gérer les comptes patients ;
* gérer les comptes médecins ;
* gérer les établissements ;
* gérer les signalements ;
* gérer les comptes suspendus ou bloqués ;
* vérifier certaines informations administratives ;
* surveiller la sécurité de la plateforme ;
* consulter les journaux techniques et de sécurité ;
* gérer les paramètres généraux de la plateforme.

## 7.1 Confidentialité

L'administrateur ne doit pas avoir automatiquement accès au contenu médical privé des patients.

L'accès aux données médicales doit être limité, contrôlé et traçable selon les règles définies par la plateforme.

---

# 8. Système de rendez-vous

Les rendez-vous Olyvera sont **uniquement physiques** dans la première version.

## 8.1 Patient

Le patient peut :

1. rechercher un médecin ou un établissement ;
2. consulter la spécialité du médecin ;
3. consulter ses disponibilités ;
4. choisir une date ;
5. choisir une heure ;
6. envoyer une demande de rendez-vous ;
7. recevoir une confirmation ou un refus ;
8. annuler le rendez-vous ;
9. consulter ses rendez-vous futurs ;
10. consulter ses rendez-vous passés.

## 8.2 Médecin

Le médecin peut :

1. définir ses horaires disponibles ;
2. recevoir les demandes ;
3. accepter un rendez-vous ;
4. refuser un rendez-vous ;
5. consulter son agenda ;
6. modifier ses disponibilités ;
7. marquer un rendez-vous comme terminé ;
8. signaler un patient absent.

---

# 9. Gestion de la famille

Chaque patient possède une liste de relations familiales.

Le patient peut :

* rechercher un utilisateur par son identifiant ;
* rechercher un utilisateur par son numéro de téléphone ;
* envoyer une demande de lien familial ;
* accepter une demande ;
* refuser une demande ;
* supprimer une relation ;
* préciser le lien familial ;
* consulter la liste de ses relations familiales.

Les relations peuvent être par exemple :

* père ;
* mère ;
* frère ;
* sœur ;
* fils ;
* fille ;
* conjoint ;
* autre membre de la famille.

## Règle importante

**Être membre de la même famille ne donne aucun accès automatique aux données médicales.**

---

# 10. Autorisations médicales

Le patient contrôle les accès à ses données médicales.

Il peut :

* voir les médecins ayant accès à son dossier ;
* autoriser un médecin à consulter son dossier ;
* retirer une autorisation ;
* consulter l'historique des accès ;
* autoriser éventuellement une personne de confiance à consulter certaines informations.

## Règles

* Un lien familial ne donne aucun accès médical automatique.
* Un rendez-vous ne donne pas automatiquement accès à tout le dossier médical.
* Le patient garde le contrôle de ses autorisations.
* Un médecin ne peut consulter que les données auxquelles il est autorisé à accéder.
* Les accès aux données médicales doivent être enregistrés dans un historique.
* Les données médicales professionnelles ne peuvent pas être librement modifiées par le patient.

---

# 11. Documents médicaux

Le patient peut consulter ses documents médicaux enregistrés sur Olyvera.

Les professionnels autorisés peuvent ajouter des documents liés à une prise en charge, notamment :

* comptes rendus ;
* résultats d'examens ;
* ordonnances ;
* documents de consultation ;
* autres documents médicaux.

Chaque document doit être associé à son auteur, sa date et, lorsque nécessaire, au patient et à la consultation correspondante.

---

# 12. Historique médical

Le dossier médical doit permettre de retrouver chronologiquement les informations médicales enregistrées par les professionnels.

Il peut notamment contenir :

* consultations ;
* diagnostics ;
* traitements ;
* prescriptions ;
* examens ;
* résultats ;
* allergies ;
* antécédents ;
* observations ;
* documents médicaux.

Le patient peut consulter son historique.

Les professionnels ne voient que les informations auxquelles leurs autorisations leur donnent accès.

---

# 13. Notifications

Olyvera pourra envoyer des notifications concernant :

* demandes de rendez-vous ;
* acceptation d'un rendez-vous ;
* refus d'un rendez-vous ;
* annulation d'un rendez-vous ;
* rappel de rendez-vous ;
* demandes de relation familiale ;
* autorisations médicales ;
* événements importants liés au compte.

---

# 14. Sécurité et confidentialité

La sécurité constitue une partie essentielle de Olyvera.

La plateforme devra notamment prévoir :

* authentification sécurisée ;
* mots de passe protégés ;
* gestion des sessions ;
* contrôle des permissions ;
* séparation des rôles ;
* contrôle des accès aux dossiers médicaux ;
* journalisation des accès ;
* protection contre les accès non autorisés ;
* sauvegardes ;
* protection des documents médicaux ;
* validation des données sensibles ;
* système de déconnexion sécurisée.

🔐 Gestion des permissions

Olyvera utilisera un système de rôles + permissions + autorisations sur les données médicales.

1. Rôles

Patient
Médecin
Établissement
Administrateur

2. Permissions
Chaque rôle possède des permissions précises : consulter, créer, modifier, supprimer, gérer, etc.

3. Données médicales
Les permissions médicales sont séparées des permissions générales.

Exemple : un médecin peut avoir le droit de consulter le dossier d'un patient, mais pas nécessairement de modifier toutes ses informations.

4. Autorisation patient → médecin
L'accès au dossier médical dépend également de l'autorisation accordée au médecin.

5. Principe du moindre privilège
Chaque utilisateur reçoit uniquement les permissions nécessaires à son rôle.

6. Traçabilité
Chaque accès ou modification importante doit être enregistré :

utilisateur ;
action ;
donnée concernée ;
date et heure ;
résultat de l'action.

7. Révocation
Une permission ou une autorisation peut être retirée. L'accès doit alors être immédiatement bloqué.

8. Protection
Aucun utilisateur ne doit pouvoir augmenter ses propres permissions.

---

# 15. Règles générales

1. Un patient possède son propre espace personnel.
2. Les données médicales sont privées.
3. Le patient contrôle les autorisations d'accès.
4. Les médecins renseignent les informations médicales professionnelles.
5. Un médecin ne peut consulter que les dossiers auxquels il est autorisé à accéder.
6. Une relation familiale ne donne pas automatiquement accès au dossier médical.
7. Un rendez-vous ne donne pas automatiquement accès à l'ensemble du dossier.
8. Les accès aux données sensibles doivent être traçables.
9. Les informations médicales importantes doivent être associées à leur auteur et à une date.
10. L'administrateur gère la plateforme sans avoir automatiquement accès aux dossiers médicaux privés.

---

# 17. Objectif du projet

Olyvera a pour objectif de créer un espace numérique permettant à une personne de retrouver et de gérer son parcours de santé tout en conservant un contrôle strict sur l'accès à ses informations médicales.

La plateforme doit privilégier :

* la confidentialité ;
* la sécurité ;
* la traçabilité ;
* la simplicité ;
* la séparation des responsabilités ;
* le contrôle des accès ;
* la fiabilité des informations médicales.
